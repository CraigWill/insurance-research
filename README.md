## 结论速览（TL;DR）

### 1. 保险的业务构成，本质是三个叠加的生意

1. **承保生意**：卖风险保障，赚"收的保费 > 赔的钱 + 花的钱"的差额（财险看**综合成本率 COR**，寿险看**三差**：死差/费差/利差）。
2. **资金生意**：保费先收、赔款后付，中间形成**浮存金（float）**，靠投资赚钱。寿险公司本质是"带负债成本的资产管理公司"。
3. **渠道与服务生意**：中介、MGA/TPA、健康管理、车后服务——**不占用资本、不承担赔付责任、赚佣金和服务费**。

> 关键判断：**第 3 类才是个人和小团队能碰的**；第 1、2 类是重资本 + 重牌照 + 重人力的生意。

### 2. "合规且健康"= 同时守住三条线

| 线 | 硬指标（中国内地，需核验最新口径） | 破线后果 |
|---|---|---|
| **偿付能力** | 核心充足率 ≥ 50%、综合充足率 ≥ 100%、风险综合评级 ≥ B 类，三者需同时达标 | 列为重点核查对象 → 限制增设分支/新业务/分红/加薪 → 严重者接管、撤销 |
| **流动性** | 各情景现金流压力测试通过、净现金流不为负 | 退保潮下即刻爆雷（"短钱长投"是历史上最主要的死因） |
| **行为合规** | 销售、理赔、消保、报行合一、反洗钱、数据安全 | 罚款、限制业务、高管撤职、市场禁入 |

### 3. 组织架构的核心不是"设多少部门"，而是**四条不可跨越的分离墙**

1. **核保 ⟂ 理赔**（"两核"独立，不得同一人/同一条线兼管）
2. **精算 ⟂ 销售/财务**（定价与准备金评估须由精算独立签字，不受业绩压力左右）
3. **风险/合规 ⟂ 业务**（第二道防线，向董事会和监管直报）
4. **内审 ⟂ 一切**（第三道防线，直接向董事会审计委员会汇报，人事与预算独立）

其余部门都可以合并、外包、分阶段搭建；这四条墙一破，公司必然出事——只是时间问题。

### 4. "One person insurance company" 的现实答案

| 解法 | 可行性 | 一句话 |
|---|---|---|
| A. 一人**持牌承保**保险公司（自己承保） | ❌ 基本不可行 | 2 亿实缴资本可以想办法，但**监管要求的最低人员配置本身就否决了"一人"**：总精算师、合规负责人、财务负责人、"两核"分离、内审独立，法定角色互斥，一个人不可能兼任 |
| B. **一人股东**的持牌保险公司（独资法人） | ⚠️ 可行但极难 | 法律上存在（外资独资寿险公司已有先例），但需控制类股东资质（百亿级总资产量级），且公司内部仍需数百人 |
| C. **独立个人保险代理人 / 一人中介**（不承保，只销售+服务） | ✅ **最现实** | 以个体工商户或小型持牌中介形式展业，零资本占用，这是"一人保险公司"的正解 |
| D. **境外 Cell Captive（租用式自保单元）** | ✅ 可行（有钱的话） | 在百慕大/开曼/美国自保州租一个 cell，不用建整家保险公司，就能"拥有自己的保险公司"，用于自有风险 |
| E. **类 MGA / 保险科技**（做能力，不做主体） | ✅ 可行 | 把定价、选品、服务、系统做成能力卖给保险公司，收管理费/分润；注意中国**核保权、理赔权、资金不得外包给中介**这条红线 |

**推荐路径**：C（现金流起步）→ 团队化 → E（类 MGA，做能力和数据）→ 若自有风险规模够大再考虑 D（自保）→ 只有在产业资本级别才谈 B。

## 本次调研的方法与局限

- **联网检索质量不足**：多次针对中国保险监管条款的检索返回大量无关结果（日本保险业法、无关营销文），未能获取权威原文。
- 因此报告主体基于行业通识与既有法规框架撰写，**所有具体数值均在 05 号文件中标注了"待核验"状态**，请以金融监管总局（nfra.gov.cn）官网原文、或委托执业律师出具的合规意见为最终依据。
- 特别提示三个**时效性强、极可能已变化**的点：偿二代二期过渡期安排、人身险预定利率上限（挂钩市场利率动态调整）、新保险合同准则（CAS 25）在非上市险企的全面实施节奏。
